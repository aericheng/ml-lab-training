## 名詞解釋（報告前先熟悉，被問到可直接答）

> 這一段不用唸出來，是給自己準備的。下面每個 Q 都是可能被問、或講稿裡會出現的名詞。

**Q：什麼是 conv-autoencoder（卷積自編碼器）？**
A：Autoencoder（自編碼器）是一種神經網路，目標是「把輸入壓縮再還原」。它分兩部分——Encoder（編碼器）把輸入壓成一個小向量（latent code），Decoder（解碼器）把這個小向量還原回原本的輸入；訓練目標就是讓「還原的」盡量接近「原本的」。「Conv」指 encoder/decoder 內部用「卷積層」，卷積層擅長抓圖片的局部特徵（邊緣、紋理、五官）。對比：用全連接層做的就是 FC autoencoder（Report Q2 那個）。

**Q：什麼是啟用函數（activation function）？ReLU、Tanh、LeakyReLU 各是什麼？**
A：神經網路每層做完線性運算後，會套一個「非線性函數」，叫啟用函數；沒有它，疊再多層都會塌縮成一層線性、學不到複雜的東西。
- **ReLU**：公式 `max(0, x)`——負的變 0、正的不變。簡單快，但負區段梯度為 0，神經元可能「死掉」（dead neuron）永遠不更新。
- **LeakyReLU**：ReLU 改良版，負的不是變 0 而是乘一個小斜率（這次用 0.2）。負區段還有梯度，避免 dead neuron。
- **Tanh**：把任何數值壓到 −1～+1 之間的 S 形曲線。用在輸出層——因為圖片正規化到 [−1, 1]，輸出層用 Tanh 剛好對應。

**Q：什麼是 BatchNorm（BN，批次正規化）？**
A：訓練時每層的輸出數值分佈會一直亂跳，讓訓練不穩。BatchNorm 在每層後面，把這一個 batch 的數值正規化成「平均 0、變異數 1」，再做可學習的縮放/平移。好處：訓練更穩、可以用更大的學習率、收斂更快。

**Q：什麼是 dilation（膨脹卷積）？**
A：普通卷積的 kernel 格子是緊鄰的；dilation 卷積把格子間隔拉開（dilation=2 就是每格中間空一格）。效果是用同樣參數量看到「更大範圍」的圖（更大的感受野），抓更大尺度的結構。

**Q：相關係數用什麼算？**
A：用 Pearson correlation（皮爾森相關係數），範圍 −1 到 +1。+1 完全正相關、0 不相關、−1 完全負相關。做法是拿兩個模型對同一批測試圖打的 anomaly score 算 Pearson correlation（程式用 `numpy.corrcoef`）。

**Q：什麼是 bottleneck（瓶頸）？**
A：指神經網路中「資訊被迫通過的窄通道」。Autoencoder 的 latent 就是 bottleneck——輸入很大、latent 很小，資訊被壓縮。瓶頸越窄/越嚴格，模型越無法「硬背」訓練資料，異常就越藏不住。

**Q：什麼是 attention（注意力機制）？**
A：給一個 query，去跟一堆候選比相似度，相似度高的拿到高權重，最後做加權總和。MemAE 就是用 attention 讓 latent z 去跟 500 個原型比對、加權組合。

**Q：什麼是 paradigm（範式）？**
A：指「解決問題的根本思路大類」。這次用到三種：(1) 重建型——學還原正常圖、用還原誤差當分數；(2) 自監督分類——自己造假標籤訓練分類器；(3) 自監督位置預測——用「預測位置」當訓練任務。不同 paradigm = 完全不同角度 → 犯的錯不一樣 → ensemble 才有效。

**Q：什麼是 DAE / VAE / MemAE / DeepSVDD / PatchSVDD？**
A：這 5 個在講稿 4.4 / 4.5 / 4.7 / 4.8 / 4.10 各段都有完整白話說明，這裡先一句話帶過：
- **DAE（去噪自編碼器）**：對輸入加雜訊、要求還原成乾淨的圖。
- **VAE（變分自編碼器）**：encoder 輸出一個機率分佈（μ 和 log σ²）而非固定向量。
- **MemAE（記憶增強自編碼器）**：encoder 跟 decoder 中間插一個「500 個原型」的記憶模組。
- **DeepSVDD**：不做重建，把正常人臉特徵全擠到一個球心附近，用「離球心多遠」當異常分數。
- **PatchSVDD**：DeepSVDD 的小塊版本，加「預測 patch 相對位置」的任務。

## 4.4 Boss v1 — DAE + Classifier  `0.68294` ❌ 退步更多

【投影片】一行描述 + 橘色教訓框。

【講稿】
「**第二個失敗，而且比 Strong 更慘。**

先解釋什麼是 **DAE（去噪自編碼器，Denoising Autoencoder）**：普通 autoencoder 是『輸入 x → 還原 x』；DAE 是故意對輸入加雜訊變成『有雜訊的 x』，但要求模型還原出『乾淨的 x』。用意是強迫模型學真正重要的結構，不要被雜訊細節騙。

作業 PDF 對 Boss 的提示之一是『加隨機 noise 加一個 classifier』。所以我做了兩件事：第一，用 DAE——對輸入加 Gaussian 雜訊，但要求還原成乾淨的圖；第二，加一個 **classifier（分類器）**，讓它分辨『乾淨圖的 latent』跟『加噪圖的 latent』。我的假設是：異常圖的 latent 應該會比較像『加噪的 latent』，所以這個 classifier 可以順便當異常偵測器。

結果退步到 0.683。

失敗的原因很關鍵：那個 classifier **訓練到第 2 個 epoch 就 100% 分對了**——太快了。這代表它根本沒有用『人臉的特徵』去分，而是抓到一個捷徑：加了噪的圖，像素的變異數本來就比較大，classifier 只要看這個統計量就能分對。

但真正的異常圖不是『加了噪的人臉』，它是完全不同類型的圖像。所以 classifier 在測試時，看到異常圖的反應，跟看到正常人臉一模一樣——對偵測異常完全沒幫助。

教訓：**加一個技術之前，要先驗證你的假設方向是對的**；還有，loss 降得很快不代表學到對的東西，它可能只是找到一個偷吃步。」

## 4.5 VAE — Variational AE  `0.73048`

【投影片】一行描述 + 來源框。

【講稿】
「Strong 跟 Boss 都失敗之後，我去查了同學公開的 reference notebook，發現 reference 用的其實是 **VAE（Variational Autoencoder，變分自編碼器）**。

先講 VAE 跟普通 autoencoder 差在哪。普通 autoencoder 的 encoder 輸出『一個固定的 latent 向量 z』。VAE 不一樣——它的 encoder 輸出的是『一個機率分佈』，具體來說輸出兩個向量：
- **μ（mu）**：這個分佈的平均值，也就是『中心在哪』；
- **log σ²**：這個分佈變異數的對數，也就是『這個分佈有多寬』。

這兩個合起來定義了一個常態分佈。然後 VAE 從這個分佈裡『採樣』出真正要用的 z——白話說就是『以 μ 為中心、隨機抖動一下』取一個點。

Loss 有兩部分：第一是**重建誤差 MSE**，還原的圖要像原圖（這個跟普通 AE 一樣）；第二是 **KL 散度（KL divergence）**，它衡量『encoder 輸出的那個分佈』跟『標準常態分佈』差多少，這一項要越小越好。

加 KL 散度的用意：它強迫整個 latent 空間長得規規矩矩、靠近標準常態。普通 AE 可以把訓練樣本隨便塞到 latent 空間的任何角落；VAE 不行——它必須把資訊壓縮成一個有結構的分佈。異常樣本塞不進這個結構，重建就會比較差。

成績 0.730，**小贏 Medium 一點點**。雖然只贏一點，但這證明了 reference 的方向是對的。」

## 4.7 MemAE v1 — 第一次突破  `0.75269`

【投影片】架構 mermaid 圖 + 「跟 Medium 的差異」表 + 「擅長的部分」清單 + 黃色 v2 教訓框 + 來源框。

【講稿】
「**這裡是第一個真正的突破——MemAE，Memory-Augmented Autoencoder（記憶增強自編碼器）。**

【指架構圖】先看架構。普通 autoencoder 是『圖片 → encoder → latent z → decoder → 還原』。MemAE 在中間多插一個東西，叫 **Memory Module（記憶模組）**。

這個記憶模組裡面，存了 500 個向量，我們叫它 **prototypes（原型向量）**，可以想成『500 個人臉的零件範本』。這 500 個向量是『可學習的參數』，訓練的時候會被慢慢調整。

運作流程是這樣：第一步，encoder 把圖片壓成一個 latent z；第二步，z **不直接用**，而是拿去跟這 500 個 prototype 一一比對相似度；第三步，用注意力機制算出對每個 prototype 的權重——越像的 prototype 權重越高；第四步，把這 500 個 prototype 按權重加權平均，組合出一個新的 ẑ；第五步，ẑ 才送進 decoder 去還原。

白話講：模型**不能自由發揮**，它只能用『500 個學好的範本』去拼湊重建。

我這個 v1 版本有一個特性：它的注意力幾乎是『平均的』——每個 prototype 的權重都差不多。所以 ẑ 大概就等於『500 個 prototype 的平均』，這個平均差不多是一張『平均臉的 latent』。結果就是——**模型把任何輸入都還原成同一張平均臉**。

【指差異表】這張表比較 MemAE 跟 Medium：encoder、decoder 完全一樣，差別只在中間多了 memory module。最關鍵看兩列——MemAE 的分數分佈寬度是 Medium 的 4 倍；而且它跟 Medium 的相關係數只有 **0.733**（其他 conv-AE 之間都是 0.99）。

【指擅長清單】解釋它擅長的三點：

**第一，強制 bottleneck（瓶頸）。** bottleneck 是『資訊被迫通過的窄通道』。MemAE 強迫 z 只能由那 500 個 prototype 組合出來——這是一個非常嚴格的限制。正常人臉可以用這些 prototype 大致組出來；但異常圖找不到對應的 prototype，硬組出來的東西跟原圖差很多 → 重建誤差大 → 異常分數高。這就是它能偵測異常的核心。

**第二，它帶來『真正不同』的訊號。** 剛說過它跟其他模型相關係數只有 0.73，意思是它『看圖的角度』跟別人不一樣。這對後面做 ensemble（模型集成）超級重要——因為 ensemble 要有效，組合進去的模型必須『犯不一樣的錯』，才能互相抵消。

**第三，訓練很穩定。** 因為它的 encoder、decoder 跟 Medium 完全一樣，只是多一個 memory module，不會有訓練不穩的問題。

成績 0.753，比整個 conv-AE 家族高了 0.02——這是第一次真正突破天花板。

【指黃色框】這裡有個最深刻的教訓。我後來做了一個 v2，**照著 paper 把『平均注意力』這個看似是 bug 的東西修好**——讓注意力變得稀疏（每次只挑 1 到 2 個最像的 prototype）。結果——**反而退步 0.08**。

為什麼？因為稀疏注意力給了異常圖一條逃生路：它可以去『找一個最像自己的 prototype』，硬湊出一個還不錯的重建。而 v1 的平均注意力沒有這條逃生路——所有東西都被迫變成平均臉。所以 v1 的『bug』其實是 feature。結論是：**paper 是對的，不代表對你的任務是對的**。」

## 4.8 DeepSVDD  `0.63745` — 單獨弱但 ensemble 神器

【投影片】架構 mermaid 圖 + 「跟前面方法的差異」表 + 「擅長的部分」 + 權重掃描表 + 來源框。

【講稿】
「**DeepSVDD（Deep Support Vector Data Description）**，這個方法跟前面所有方法都不一樣——它**完全不做重建**。

【指架構圖】它的想法是這樣：用一個 encoder，把每一張正常人臉都映射成一個特徵向量。訓練的目標是——讓所有正常人臉的特徵向量，**全部擠到一個球的中心點 c 附近**。Loss 就是『每個樣本的特徵到中心 c 的距離』，這個距離要越小越好。

推論的時候：拿一張測試圖，算它的特徵離中心 c 多遠——**離越遠就越異常**。直覺是：正常人臉訓練時被擠到中心附近，異常圖沒被訓練過，它的特徵會落在離中心很遠的地方。

實作有三個關鍵細節，不做的話模型會『崩潰』：第一，所有卷積、全連接層不能有 bias；第二，BatchNorm 不能有可學習的縮放；第三，中心點 c 要先用初始模型算一次、然後『凍結』不能再被訓練。為什麼要這樣？因為如果不鎖，模型會找到一個作弊解——把所有圖都輸出成 0，這樣距離全部是 0、loss 完美，但模型其實什麼都沒學。這種沒用的解叫 **degenerate solution（退化解）**。

【指差異表】跟前面方法的差別：前面全部是『重建誤差』當異常分數，DeepSVDD 是『特徵到中心的距離』。

它單獨的成績只有 0.637，**很弱**。但是——【指權重掃描表】重點來了——**它跟其他模型的相關係數只有 0.1 到 0.32**，超級不一樣，因為它是完全不同的方法。所以把它用一個小權重 0.3 倍加進 ensemble，可以把 Private AUC 推到 0.7598。它單獨弱，但是個 ensemble 的神隊友。

不過要先說，後面加了更強的 PatchSVDD 之後，最終的 best ensemble 反而把 DeepSVDD 拿掉了——因為這時候它已經變成雜訊了。」

## 4.9 CutPaste — 第二次突破  `0.72454`

【投影片】架構 mermaid 圖 + 「兩種 score 變體對比」表 + 「跟前面方法的差異」表 + 權重掃描表 + 來源框。

【講稿】
「**第二個突破——CutPaste，一種自監督方法。**

【指架構圖】想法是這樣：對每張訓練圖做資料增強——**剪一塊 patch 貼到同一張圖的隨機位置**，做成兩種假異常（方塊形跟刮痕形）。然後訓練一個三分類器：分辨『正常 / 貼了方塊 / 貼了刮痕』。

重點在推論。我試了兩種異常分數：
【指對比表】
- 第一種，直接用分類器：『1 減正常的機率』——只有 0.599，**很弱**。
- 第二種，用 **Mahalanobis 距離**：拿 encoder 的特徵，去算它離訓練資料分佈多遠——0.725，**強很多**。

為什麼差這麼多？因為分類器問的是『這張圖有沒有被剪貼過』，異常圖沒有被剪貼，分類器就答『沒有』，給低分——這是錯的。而 Mahalanobis 問的是『這個特徵離正常分佈多遠』，異常圖離很遠，正確給高分。**Mahalanobis 繞過了分類器的認知盲點，直接用 encoder 學到的特徵。**

（補充：**Mahalanobis 距離**是一種「考慮資料分佈形狀」的距離——它不只看『離平均多遠』，還會根據資料各方向的變異程度做調整。這裡是拿訓練集的特徵 fit 一個高斯分佈，再算測試圖的特徵離這個分佈多遠。）

【指差異表】跟前面的差別：前面是 unsupervised，CutPaste 是 **self-supervised**——它自己造假標籤來學。而且它跟 MemAE 的相關係數只有 0.28，非常不一樣。

【指權重掃描表】把 CutPaste 用 3 倍權重加進 ensemble，AUC 衝到 **0.77978，過了 Strong 門檻**。」

## 4.10 PatchSVDD — 第三次突破（學歪方向反轉成寶藏）  `0.76396`

【投影片】架構 mermaid 圖 + 全負相關表 + 反轉前後對照表 + 「跟前面方法的差異」表 + 「擅長的部分」 + 權重掃描表 + 黃色框 + 來源框。

【講稿】
「**第三個突破——PatchSVDD，這是整份作業最反直覺的故事。**

【指架構圖】PatchSVDD 是剛剛 DeepSVDD 的『小塊（patch）』版本。做法：第一，把一張 64×64 的圖，切成 9 個小塊，每塊 32×32，排成 3×3；第二，對每個小塊做 DeepSVDD——每個小塊的特徵都要靠近中心；第三，額外加一個任務叫『位置預測』——給模型一個小塊跟它的某個鄰居，要它預測『這個鄰居在哪個方位』（8 個方向選一個）。這個位置預測任務，會強迫 encoder 學到『人臉的部位應該長在哪裡』這種結構知識。

訓練結果：位置預測的準確率高達 **99.57%**——模型幾乎完美學會了人臉結構。**但是拿去 Kaggle 一測，AUC 只有 0.236**——比亂猜的 0.5 還低！

【指全負相關表】更怪的是：它跟所有其他模型的相關係數，**全部是負的**，大概都在 −0.27。負相關的意思是：它的排序跟別人『相反』——別人覺得是異常的，它覺得是正常的。

為什麼會學歪方向？因為位置預測這個任務太成功了，encoder 全力去學『結構』；但『靠近中心』那個 loss 反向利用了這個結構訊號，結果變成『結構越正常的圖，特徵離中心反而越遠』。所以它對正常人臉給高分、對異常圖給低分，整個排序反了。

解法非常簡單——【指反轉表】**把分數反轉，用 1 減掉原始分數**。原本 0.236，反轉後變成 **0.764**。數學上很直觀：任何模型 AUC 是 x，把分數反過來，AUC 就變成 1 減 x。0.236 加 0.764 剛好等於 1。

【指黃色框】這給我一個很反直覺的體會：**AUC 小於 0.5 不代表是壞模型**——它可能是完美地學到了一個『反向的訊號』。只要它跟其他模型是負相關、而它自己的 AUC 接近 0，把它反轉過來就是一座金礦。

【指權重掃描表】把反轉後的 PatchSVDD 用 5 倍權重加進 ensemble——AUC 從 0.78 一路爆衝：權重 1 倍就破 0.80、過 Boss 門檻，3 倍到 0.83，5 倍 **0.83973，這就是最終的最好成績**。」

## 4.11 最終 best ensemble  `0.83973 / 0.83490`

【投影片】6 個模型的 ensemble 程式碼 + mermaid 圖 + 綠色「3 paradigm」框 + rank vs z-score 表。

【講稿】
「最後把所有東西組合起來。

【指程式碼 / mermaid 圖】最終的配方是 **6 個模型的 rank ensemble**：
- 三個不同 random seed 的 MemAE，各權重 1；
- 一個 VAE，權重 1；

### 7.4 Report Q2 — Latent Manipulation（潛在空間操控）

【投影片】`q2_latent_manipulation.png` — 5 個面板：原圖、z 不動的重建、z[0]×2、z[1]×2、z[2]×2。

【講稿】
「最後 7.4 這張圖，是作業 **Report 的第二題**——要先說明，它跟前面衝 Kaggle 分數的部分是**分開的**。作業評分有兩塊：一塊是 Code submission，就是前面 4.1 到 4.11 衝 AUC 的競賽；另一塊是書面 Report。這一題屬於 Report，**不提交 Kaggle，只做分析**。

題目要求：訓練一個 **fully-connected autoencoder**，也就是全連接的自編碼器——跟前面的卷積 autoencoder 不一樣；然後調整 latent 的至少兩個維度，畫出原圖跟調整後的重建圖、描述差異。

什麼是 **latent manipulation（潛在空間操控）**？autoencoder 會把圖片壓成一個小的向量 z；latent manipulation 就是**手動去改 z 的數值，看 decoder 還原出來的圖怎麼變**——藉此理解 z 的每個維度各自控制了什麼。

這個 FC autoencoder 有個關鍵設計：**latent 維度只有 3**。為什麼故意設這麼小？因為這樣才能『一個維度一個維度』去看它控制什麼——如果是 256 維就完全看不出來。代價是 3 維瓶頸太緊，重建一定很模糊。

【指圖】我拿測試圖第 0 張、一個戴帽子的男子，它的 latent z 是 [−9.60, 2.44, −4.33]。把這 3 個維度分別乘以 2，看重建怎麼變：
- **z[0] 乘 2**：整張圖變暗、髮型變長、臉變圓——所以 z[0] 大概控制亮度、性別、髮量。
- **z[1] 乘 2**：臉變亮、偏粉紅、變柔和——z[1] 控制膚色明度、偏女性的特徵。
- **z[2] 乘 2**：變更亮、更女性化——z[2] 也涉及性別跟膚色。

最有意思的是：我**沒有**告訴模型哪個維度該代表什麼，但因為 latent 只有 3 維，模型被**逼著**把『整個資料集變異最大的方向』塞進這 3 個維度。對人臉資料，最大的變異就是性別膚色、亮度、髮型臉型——所以這 3 個維度自然就對應到這些語意。**這跟 PCA 主成分分析的精神類似，只是 autoencoder 學的是非線性的主軸。**

這題也順便說明了：為什麼 FC autoencoder 不適合拿來做異常偵測——3 維重建太模糊，正常跟異常的重建誤差都偏大，差距被淹沒。」

## 8. 階段性結論

【投影片】綠色框（4 baseline 餘裕表）+ 核心發現清單 + 證偽的迷思清單。

【指綠色框】四個 baseline 全部通過，而且都有餘裕：Simple 多 0.31、Medium 多 0.11、Strong 多 0.07、Boss 多 0.04。從 0.669 進步到 0.840，總共 0.171。

**核心發現有四個：**
1. MemAE 的 memory bottleneck——強制平均臉重建，是第一次突破。
2. CutPaste 的 Mahalanobis——自監督加上用距離當分數，第二次突破。
3. PatchSVDD 反轉——學歪方向反轉成寶藏，第三次突破。
4. Rank ensemble 加上三種不同 paradigm——錯誤不相關才是關鍵。

**而且這次作業證偽了四個常見的迷思：**
- 加深網路不一定變強——Strong 跟 ResNet 都證明了；

- AUC 小於 0.5 不一定是壞模型——PatchSVDD 反轉就變寶藏；

我的報告到這裡，謝謝大家。」

## 附錄：可能的 Q&A 準備

**Q：為什麼不直接用 pre-trained model？**
A：作業規定禁止使用 pre-trained model 跟額外資料。

**Q：MemAE 的 memory module 500 個原型怎麼決定的？**
A：參考 paper 範圍（100–2000），取中間值 500；重點不在數量，而在 v1 的注意力是平均的，這才是讓它 work 的原因。

**Q：為什麼 rank ensemble 比 z-score 好？**
A：各模型分數尺度差異極大（MemAE ~0.1、CutPaste Mahalanobis ~100、DeepSVDD ~0.0001）。z-score 雖然標準化了，仍會被少數極端值影響；rank 完全只看排序，最穩。

**Q：PatchSVDD 反轉是不是作弊？**
A：不是。任何模型 AUC 是 x，把分數反轉（1−score）就會得到 1−x，這是純數學。重點是它跟其他模型負相關，提供真正互補的訊號。

**Q：花最多時間在哪？**
A：第一階段卡在 0.73 最久——試了 Medium、VAE、ResNet、各種 conv-AE ensemble 都沒用。轉折點是去查 reference、改用 MemAE 這種非重建 bottleneck 的方法。

**Q：MemAE 重建異常圖時，異常圖會變成什麼樣子？會比較有輪廓嗎？**
A：剛好相反——**異常圖的重建不會變得有輪廓，它會被重建成一張跟正常圖一模一樣的「平均臉」**。MemAE 不管輸入是什麼（正常臉、雜誌封面、戴帽子的人），重建出來都是同一張模糊平均臉。
重點不在「重建長怎樣」（都一樣），而在「重建跟原圖差多少」：正常人臉本來就接近平均臉 → 差距小 → score 低；異常圖（例如雜誌封面）跟平均臉差很多 → 差距大 → score 高。
對比其他模型：VAE / ResNet 反而**會**把異常圖的輪廓、顏色大致描出來——重建得「還算像」原圖 → MSE 不夠大 → 卡在 0.73。所以「會把異常圖重建得有輪廓」的模型反而是失敗的；MemAE 的強項正是它「笨到只會畫平均臉」，逼異常圖無處可逃。
（這點在 7.3 的 `03_recon_memae.png` 圖上看得最清楚——Input 那排五花八門，Recon 那排全是同一張平均臉。）
